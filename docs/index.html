How it works

  1. Download OMEGA-macOS.zip or OMEGA-Windows.zip from the latest release.
  2. Mac: right-click install-mac.command → Open. Windows: double-click install-windows.bat.
  3. Put OMEGA at the end of your Master.
  4. Auto input → pick a Universe → drag the galaxy → Match target.
  5. Use COMPARE to decide with your ears, not with volume.
